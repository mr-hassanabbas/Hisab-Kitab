# Version 1 User Guide

## Welcome to Marenii Voice Assistant - Version 1

Marenii Version 1 is your advanced AI voice assistant for managing construction business operations. This guide covers all the enhanced features including advanced voice recognition, expanded tools, and improved security.

## What's New in Version 1

### Advanced Voice Features
- **Better Recognition**: Whisper.cpp integration for improved accuracy
- **Multi-Language**: Automatic detection of Urdu, Hindi, and English
- **Noise Reduction**: Background noise cancellation for clearer speech
- **Smart Detection**: Voice activity detection to know when you're speaking

### Expanded Capabilities
- **More Tools**: 18 tools including payments, projects, materials, and reports
- **Context Awareness**: Remembers your recent projects and workers
- **Conversation Memory**: Understands follow-up questions (e.g., "usme" refers to last project)
- **Advanced Security**: Risk-based confirmation and comprehensive logging

### Enhanced Experience
- **Rich Feedback**: Visual indicators showing confidence and processing status
- **Settings**: Customize language, voice speed, and preferences
- **Advanced Search**: Filter and search in command history
- **Analytics Dashboard**: View usage statistics and insights

## Advanced Features

### Conversation Memory

Version 1 remembers context across multiple turns:

**Follow-up Questions:**
- **Before**: "Show project for Liberty Tower"
- **Follow-up**: "What's the status?" → Marenii understands you're asking about Liberty Tower
- **Before**: "Mark Ahmed present"
- **Follow-up**: "How much should I pay him?" → Marenii knows you're referring to Ahmed

**Pronoun Resolution:**
- "Usme" → Refers to last mentioned project
- "Usko" → Refers to last mentioned worker
- "Isme" → Refers to last mentioned project

### Multi-Language Support

Marenii automatically detects the language you're speaking:

**Examples:**
- "حاضری لگانا" → Urdu detected
- "Attendance lagao" → Roman Urdu detected
- "Mark attendance" → English detected
- Mixed: "Mujhe attendance chahiye" → Mixed language detected

### Settings Customization

Access settings by clicking the gear icon next to the microphone:

**Language Preference:**
- Auto Detect (recommended)
- Urdu
- Hindi
- English

**Voice Settings:**
- Speed: Adjust speech rate (0.5x - 1.5x)
- Pitch: Adjust voice pitch (0.5x - 1.5x)

**Sensitivity:**
- Microphone sensitivity (0% - 100%)
- Higher = more sensitive to quiet sounds

**Confirmation Level:**
- None (not recommended)
- Simple (Yes/No)
- Detailed (with information)
- Two-Factor (highest security)

**Privacy:**
- Command history retention (7-90 days)
- Enable/disable context memory
- Enable/disable conversation memory

## Security Features

### Risk-Based Confirmation

Marenii dynamically adjusts confirmation requirements based on risk:

**Low Risk (No Confirmation):**
- Simple queries (show attendance, get worker info)
- Read operations by trusted users

**Medium Risk (Simple Confirmation):**
- Create worker (for non-owner users)
- Add expense
- Update records

**High Risk (Detailed Confirmation):**
- Delete operations
- Large payments (>10,000)
- Unusual time patterns

**Critical Risk (Two-Factor):**
- Delete projects
- Very large payments (>100,000)
- Multiple deletions in short time

### Audit Logging

All your actions are logged for security:

**Logged Events:**
- Every voice command with timestamp
- Intent classification results
- Entity resolution attempts
- Tool execution results
- Security decisions
- Errors and failures

**Access:**
- Available to administrators
- Searchable by user, date, or event type
- Exportable for compliance

### Anomaly Detection

Marenii watches for unusual patterns:

**Detected Anomalies:**
- Unusually high command frequency
- Activity at unusual times
- Unusual amounts (very high or very low)
- High error rates
- Unusual commands for your usage pattern

**Response:**
- Alerts for suspicious activity
- May require additional verification
- Logs anomaly for security review

### Rate Limiting

To prevent abuse and ensure fair usage:

**Limits:**
- 30 commands per minute per user
- Operation-specific limits (e.g., 5 delete operations per minute)
- 1000 commands per minute system-wide

**Adaptive Throttling:**
- Repeated violations lead to temporary blocking
- Automatic unblock after cooldown period
- Warnings before blocking

## Tips for Better Accuracy

### Voice Recognition Tips

1. **Speak Clearly**: Enunciate words clearly, especially for technical terms
2. **Moderate Speed**: Speak at a normal pace, not too fast or slow
3. **Reduce Background Noise**: Find a quiet environment for best results
4. **Use Natural Phrasing**: Speak as you would in normal conversation
5. **Wait for Response**: Let Marenii complete before giving next command

### Language Tips

1. **Stick to One Language**: Complete your command in one language when possible
2. **Use Common Terms**: Use standard construction business terms
3. **Be Specific**: Include project names, worker names, and amounts clearly
4. **Use Dates Properly**: Specify dates clearly (today, tomorrow, or specific dates)

### Conversation Tips

1. **Reference Context**: Use pronouns for follow-up questions ("usme", "usko")
2. **Be Specific About References**: If context is ambiguous, use full names
3. **Allow Context Time**: Give Marenii a turn to process context
4. **Clear History**: Start fresh conversation if context is confusing

### Efficiency Tips

1. **Batch Operations**: Use bulk commands when possible
- "Mark Ahmed, Ali, and Raza present" (one command vs three)
2. **Use Reports**: Generate reports instead of individual queries
- "Show attendance summary" (instead of asking about each worker)
3. **Leverage Context**: Use follow-up questions instead of repeating information
- "Usme kya status hai?" (instead of "What is the status of Liberty Tower?")

## Troubleshooting

### Voice Recognition Issues

**Problem**: Marenii doesn't understand you

**Solutions**:
1. Speak more clearly and slowly
2. Reduce background noise
3. Try using English instead of Urdu
4. Check confidence score in feedback UI
5. Try a different phrasing

**Problem**: Wrong language detected

**Solutions**:
1. Set language preference in settings
2. Speak clearly in preferred language
3. Use language-specific terms
4. Try saying the command in the intended language

### Context Issues

**Problem**: Marenii forgets context

**Solutions:**
1. Check if session has expired (30-minute timeout)
2. Re-establish context by mentioning project/worker again
3. Check if context memory is enabled in settings
4. Start a new conversation

### Security Issues

**Problem**: Command requires too much confirmation

**Solutions**:
1. Adjust confirmation level in settings
2. Check if you're trusted user (owner/admin)
3. Check if command is marked as high-risk
4. Adjust operation amount if too high

### Performance Issues

**Problem**: Responses are slow

**Solutions**:
1. Check if using Whisper.cpp (initial load may be slow)
2. Check network connection
3. Check AI model being used (faster models for simple tasks)
4. Check if caching is working (repeated commands should be faster)
