# Hisab Kitab MVP - User Guide

## Welcome to Marenii Voice Assistant

Marenii is your AI voice assistant for managing construction business operations. This guide will help you get started with voice commands in Urdu, English, and mixed languages.

## Getting Started

### First Time Setup

1. **Grant Microphone Access**: When prompted, allow microphone access in your browser
2. **Position Yourself**: Speak clearly into your microphone (2-3 feet away is ideal)
3. **Start Listening**: Click the orange microphone button to begin
4. **Give Commands**: Speak naturally in your preferred language

### Language Support

Marenii understands:
- **Urdu**: حاضری لگانا، مزدور بنانا، خرچہ لگانا
- **English**: Mark attendance, create worker, add expense
- **Roman Urdu**: Attendance lagao, worker banayein, expense add karein
- **Mixed Language**: Any combination of the above

## Tips for Better Voice Recognition

### Speaking Tips

1. **Speak Clearly**: Enunciate words clearly, especially for technical terms
2. **Moderate Speed**: Speak at a normal pace, not too fast or slow
3. **Reduce Background Noise**: Find a quiet environment for best results
4. **Use Natural Phrasing**: Speak as you would in normal conversation
5. **Wait for Response**: Let Marenii complete before giving next command

### Language Tips

1. **Stick to One Language**: Complete your command in one language when possible
2. **Use Common Terms**: Use standard construction business terms
3. **Be Specific**: Include project names, worker names, and amounts clearly
4. **Use Dates Properly**: Specify dates clearly (today, tomorrow, or specific dates)

### Error Recovery

If Marenii doesn't understand:

1. **Try Rephrasing**: Use different words for the same command
2. **Simplify Command**: Break complex commands into simpler ones
3. **Use English**: Try English if Urdu recognition fails
4. **Use Text Input**: Click the input field to type commands manually

## Command History

### Viewing History

1. Click the "History" button (clock icon) next to the microphone
2. Recent commands will be displayed with timestamps
3. Click on any command to see details
4. Success (✓) and failure (✗) status is shown

### Clearing History

Click "Clear History" at the bottom of the history panel to remove all recorded commands.

## Understanding Marenii's Responses

### Success Responses

When commands succeed, Marenii will:
- Confirm the action in the same language you used
- Provide details of what was done
- Ask if you need further help

### Error Responses

When commands fail, Marenii will:
- Explain what went wrong in simple terms
- Suggest how to fix the issue
- Offer to try again

### Clarification Requests

When information is unclear, Marenii will:
- Ask for missing information
- Provide options if multiple matches exist
- Wait for your response before proceeding

## Troubleshooting

### Voice Recognition Issues

**Problem**: Marenii doesn't understand you

**Solutions:**
- Speak more clearly and slowly
- Reduce background noise
- Try using English instead of Urdu
- Move closer to microphone
- Check if microphone is working in other apps

### AI Response Issues

**Problem**: Marenii takes too long to respond

**Solutions:**
- Check your internet connection
- Use simpler commands
- Try again (network might be slow)
- Check if OpenRouter API is working

### Permission Issues

**Problem**: Marenii says you don't have permission

**Solutions:**
- Check if you're logged in
- Verify your user role
- Contact administrator for access
- Try a different command that doesn't require special permissions

## Advanced Tips

### Complex Commands

You can combine multiple pieces of information:

"Mark Ahmed present for construction project with 500 advance"

Marenii will understand:
- Worker: Ahmed
- Status: Present
- Project: Construction project
- Advance: 500

### Date Specifications

Use these date formats:
- "Today" / "آج" → Current date
- "Yesterday" / "کل" → Previous day
- "Tomorrow" / "کل" → Next day
- Specific dates: "2026-08-15"

### Amount Specifications

Use these amount formats:
- Numbers: "5000" / "پانچ ہزار"
- Currency: "5000 rupees" / "5000 روپے"
- Context: "5000 for cement" / "سیمنٹ کے لیے 5000"
